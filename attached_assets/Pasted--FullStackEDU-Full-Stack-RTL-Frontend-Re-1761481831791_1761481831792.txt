בנה אפליקציית ווב מלאה בשם FullStackEDU ללימוד Full-Stack, בשפה העברית וביישור RTL, עם Frontend ב-React (Vite) ו-Backend ב-Node.js/Express ו-MongoDB (Mongoose). האפליקציה תאפשר הרשמה/כניסה, מעקב התקדמות בכל קורס ושיעור, שאלות אמריקאיות בסוף כל שיעור, חסימת מעבר לשיעור הבא עד למענה נכון על כל 5 השאלות, והצגת היסטוריית למידה לכל משתמש.

טכנולוגיות וארכיטקטורה

Frontend: React + Vite, TypeScript, React Router, Context/Redux (לבחירתך) לניהול מצב, RTL מלא (dir="rtl", lang="he"), Tailwind CSS או CSS מודרני.

Backend: Node.js + Express, TypeScript (עדיף), JWT Auth, bcrypt להצפנת סיסמאות, Mongoose ל-MongoDB.

DB: MongoDB עם קולקציות: users, courses, lessons, quizzes, progress.

אימות: JWT (Access + Refresh), Middleware לנתיבי API מוגנים.

ולידציה: Zod/Joi לסכמות בקלטי API.

בדיקות נכונות לשאלות: בצד השרת בלבד (אין להחזיר תשובות נכונות ללקוח).

פריסת קבצים (Monorepo):

/fullstackedu
  /client  (React + Vite)
  /server  (Express + Mongoose)
  package.json (scripts להרצה מקבילה)

מודל נתונים (Mongoose)

User: { email, passwordHash, displayName, createdAt }

Course: { slug, titleHE, descriptionHE, order, topics: [string], levelRange: "מתחיל–בינוני+", coverIcon }

Lesson: { courseSlug, slug, titleHE, order, contentHE (HTML/MD), examples: [{titleHE, code, expectedOutput}], requiresScore: 100 }

Quiz: { lessonId, questions: [{ promptHE, choicesHE: [string], correctIndex: number }] }

Progress: { userId, courseSlug, lessonSlug, status: "locked"|"in-progress"|"done", score: number, answers: [{questionIndex, chosenIndex, isCorrect}], updatedAt }

אינדקסים מתאימים על userId+courseSlug+lessonSlug.

Endpoints (דוגמא)

Auth:

POST /api/auth/register {email, password, displayName}

POST /api/auth/login {email, password} → JWT

POST /api/auth/refresh

Courses & Lessons:

GET /api/courses → רשימת קורסים + אחוז התקדמות למשתמש הנוכחי

GET /api/courses/:slug/lessons → רשימת שיעורים (כולל סטטוס נעול/פתוח)

GET /api/lessons/:lessonSlug → תוכן שיעור ללא פתרונות

GET /api/lessons/:lessonSlug/quiz → 5 שאלות (ללא ציון התשובה הנכונה)

Progress & Quiz:

POST /api/lessons/:lessonSlug/quiz/submit {answers:[index,...]}

השרת בודק, מחזיר {correctCount, score, passed: boolean}.

אם passed === true (כל 5 נכונות), עדכן Progress ל-done ושחרר את השיעור הבא.

GET /api/progress/overview → אחוז התקדמות כללי + לפי קורס.

Middleware:

requireAuth לכל נתיבי הלמידה/התקדמות.

lockGuard שמוודא ששיעור N פתוח רק אם שיעור N-1 done.

לוגיקת פתיחה/נעילה

שיעור ראשון בכל קורס: פתוח תמיד.

כל שיעור נוסף: locked עד שהשיעור הקודם done.

done = 5/5 נכונות (ציון 100). ניסיון חוזר מותר.
